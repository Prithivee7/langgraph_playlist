EPISODE 6 · THE MERGE PROBLEM
Appending by hand is fragile.
Sequential: each node must remember

Works… but only if every node re-reads and re-appends.
Parallel: both read the same start
start: []
A writes ["A"]
B writes ["B"]
overwrite → ["B"]
A's note is gone.
A reducer moves the merge logic out of every node and onto the field, once.
