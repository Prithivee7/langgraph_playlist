EPISODE 7 · THE ROUTER
A router is just a function.
def route_by_score(state) -> str: if state["score"] < 50: return "reject" elif state["score"] < 80: return "interview" else: return "strong_match"
1Reads the current state
2Returns a node name (a string)
3Or a list of names
It chooses the next node. It does not change any state.
state innode name out< 50 · < 80 · else
