EPISODE 5 · WHAT CHANGES
Four things look different.
No state schemadata flows through function arguments and return values
No edgescontrol flow is just calling one task after another
Futurestasks return a future, so call .result() to wait
No static graphthe "graph" only exists at runtime, inferred from which tasks got called
